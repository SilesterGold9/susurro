# Maintain verification skill

**Deprecated.** The constitution (commitment F) subsumes this skill. Run
`/constitution` to regenerate the per-project profile, which includes the
verification recipe.

This skill is retained only for projects that already have a verification
skill generated by earlier Conclave versions. New projects should use the
constitution.
