## Purpose

Offline-first voice dictation for Linux (Hyprland) + Windows. Local STT by
default (whisper.cpp), optional free-tier cloud (Groq, NVIDIA NIM) when
online. Talk-to-text that works even when the internet does not.

## Constraints

- `core/` defines behavior only and never imports a platform crate.
  Platform code lives in `adapters-*`. (CONTRIBUTING, ADR 003)
- Validation happens at the edges: CLI parsing, adapter constructors,
  Tauri commands.
- Every side effect is gated by a session-keyed ticket; storage degrades
  instead of blocking dictation; cleanup fails open to the raw transcript.
- Conventional commits (`feat(core): ...`, `fix(linux): ...`), one concern
  per commit. Migrate callers in the same pass; delete the legacy API,
  never leave compatibility layers.
- `app-tauri/src-tauri` is excluded from the cargo workspace (standalone
  crate with its own lockfile); CI covers it in a separate job.
- A Windows-only failure is a real finding, never a flake (CI runs
  Ubuntu + Windows).

## Canons in force

- **prove-it-works** -- adopted. The CONTRIBUTING recipe is law: fmt,
  clippy with `-D warnings`, workspace tests, `doctor`, mock `listen`;
  plus the Tauri side (`npm run build`, backend clippy).
- **fix-root-causes** -- adopted. Reproduce with `doctor` plus mock
  `listen` before theorizing; one symptom patched while the shape lives
  on elsewhere is a reloaded landmine.
- **idempotent** -- adopted. `bench`/`stt-bench` persist the winner;
  retries and restarts converge (storage degrades, cleanup fails open).
- **subtract-before-you-add** -- adopted. One concern per commit; remove
  dead weight before building on the base.
- **migrate-callers** -- adopted. Public-surface changes migrate callers
  in the same pass and delete the legacy API (CONTRIBUTING says so
  explicitly).
- **encode-lessons-in-structure** -- adopted. A review note that fires
  twice becomes a type, a check, or a test, not prose. `contracts/`
  is the standing mechanism: every adapter must pass the port suite.
- **boundary-discipline** -- adopted. Narrow at CLI parsing, adapter
  constructors, Tauri commands. Trust the core; distrust the perimeter.
- **model-the-domain** -- adopted. Port traits in `core/`; registries
  for dictionary, profiles, privacy routing, tickets. No scattered
  string comparisons.
- **type-system-honesty** -- adopted. Enforced by rustc plus
  `clippy -- -D warnings`; `anyhow`/`thiserror` on fallible paths;
  frontend guarded by `tsc --noEmit`.
- **never-block-on-the-human** -- adopted. Dictation never waits:
  storage degrades, cleanup fails open, cloud falls back to local.

## Prove it works

- `cargo clippy --workspace --all-targets -- -D warnings`
- `cargo test --workspace`
- `cargo run -p susurro-cli -- doctor`
- `cargo run -p susurro-cli -- listen --mock --stdout`

  - `npm run build`
  - `cargo clippy --all-targets -- -D warnings`

Short forms via `just` (recipes stay thin, same commands CI runs):

### Prove

- `cargo fmt --check` exits 0 (no diff).
- `cargo clippy -- -D warnings` exits 0 (zero warnings, both workspaces).
- `cargo test --workspace` exits 0, all tests passing including `contracts/`.
- `doctor` reports mic, tools, model, keys, updater reachability OK.

### Gotchas

- Linux needs `libasound2-dev` + `pkg-config`; the Tauri app also needs
  `libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf`
  plus `npm ci` in `app-tauri/`. Windows builds on stable Rust, no setup.
- `just` is not installed by default: `cargo install just`.
- Hardware proofs need a model file
  (`~/.local/share/susurro/models/base.en.bin` or `SUSURRO_MODEL`;
  fetch with `susurro model-fetch`), and for paste `wl-copy` +
  `ydotool`. Without them, prove with `--mock`. The engine is
  linked: `whisper-cli` is only needed for `--engine cli` proofs.
- CI cancels superseded runs per push (concurrency group); a green badge
  on an old push proves nothing about the current one.

## CI

`.github/workflows/ci.yml`, two jobs, both on push and PR:

- **lint-test** (`ubuntu-latest`, `windows-latest`): `cargo fmt --check`,
  `cargo clippy --workspace --all-targets -- -D warnings`,
  `cargo test --workspace`. Replicate locally with `just lint` +
  `just test-contract`.
- **tauri-check** (`ubuntu-22.04`, `windows-latest`): `npm ci` +
  `npm run build` in `app-tauri/`, backend clippy in
  `app-tauri/src-tauri`.

Releases (`release.yml`) run on `v*` tags: signed Tauri bundles
(AppImage/.deb; MSI/NSIS on Windows) plus CLI binaries and `latest.json`.

## Boundaries

- Validation at CLI parsing (`cli/`), adapter constructors
  (`adapters-*/`), Tauri commands (`app-tauri/src-tauri/`).
- `core/` trusts its inputs; the perimeter distrusts everything.
- Human to confirm: exact ticket-gating points for new side effects.

## Domain

- `core/`: state machine, pipeline, port traits. No platform imports.
- Adapters: audio capture/VAD/earcons, local STT (whisper.cpp,
  OpenVINO offload), cloud STT (OpenAI-compatible, fallback chain,
  turbo race), cleanup (regex, Ollama fail-open), Linux paste
  (Hyprland socket, wl-copy/ydotool), Windows hotkey/paste.
- `storage/`: SQLite history, tickets, dictionary, profiles, settings.
- `contracts/`: port contract suite every adapter must pass.
- Key runtime maps: per-app privacy routing (local-only), per-app
  tone profiles, custom vocabulary, session event log (`replay`).
